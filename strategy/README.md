open-ended wishlists. See `AGENTS.md`'s `strategy/` entry for the full
convention — in short, this is **subjective, top-down material**, not
verified fact, and isn't held to `reference/`'s or `projects/`'s
fact-checking bar. No lifecycle, no `Projects.md` row.
