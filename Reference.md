# Reference — subject catalog

Enduring, non-lifecycle knowledge lives in `reference/` — standing
analysis or synthesis that's true independent of any one project's
status, rather than a project working toward a deliverable. Flat, no
subdirectories: a note commonly belongs to more than one subject at
once, which a folder location can't represent — tagged instead with the
controlled `topics:` vocabulary below. Check this list before inventing
a new topic tag.

## Controlled vocabulary

- `outreach` — external-facing programs and messaging
- `identity` — what ComDev is/offers as a collective
- `governance` — ASF/PMC authority structure, roles, process
- `terminology` — naming/language questions
- `tooling` — infrastructure or software built to support a program
- `ai-agents` — agent-mediated tooling specifically
