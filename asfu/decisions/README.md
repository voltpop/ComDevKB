# ASFU decisions

Decision records for the ASF university outreach effort (ASFU).

Template: MADR (https://adr.github.io/madr/), chosen 2026-11-25. The template is in `TEMPLATE.md`.

| Setting | Value |
|---|---|
| Owner | Drew Foulks |
| Numbering | `ADR-NNN-slug.md`, one more than the highest |
| Ruling | Only the owner ratifies. Agents draft as `proposed`. |
| Landing | Branch and pull request. The owner merges. |

Known lint: bowerbird reads this folder as part of the `asfu` note bundle,
so it flags MADR status words (`proposed`, `accepted`) as outside OKF's
`draft | stable | deprecated`. The ADRs keep MADR's own words. Also,
`INDEX.md` is regenerated by `adr-index.py`, which drops its frontmatter:
re-add `type` and `description` after running it.
